# Privacy Policy

_Last updated: 20 October 2026_

## Summary

**Chronoverse collects nothing.** The package has no analytics, no tracking, no advertising, no
telemetry, no crash reporting, no accounts and no network access of its own.

## Details

- The Software runs entirely inside the application that includes it, on the device where that
  application runs.
- It does not send any data anywhere, and it does not open network connections.
- It does not read contacts, location, files, the device calendar or any other personal data on
  its own. Event data, attendee details, notes and other information exist only because the
  developer of the host application passes them to the Software, and they stay in that
  application's memory.
- It does not store data on disk, in cookies or in any other persistent storage.
- It reads the device clock and, where the host application asks it to, the device's local
  time-zone offset, only to perform date and time calculations.

## Applications that use Chronoverse

Developers who include the Software in their products are the controllers of any personal data
those products process (for example events, attendee names and email addresses). They are solely
responsible for their own privacy policies, consent, security and compliance with data-protection
laws. The authors and contributors of Chronoverse have no access to that data and accept no
responsibility for it.

## Example application and documentation

The example application uses invented sample data only. Email addresses and links in the
documentation are placeholders.

## Changes

This policy may change with a future release. The version included with the copy of the
Software you use applies to that copy.
