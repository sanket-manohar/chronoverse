Features

Built for every kind of product

Booking, scheduling, planning, fitness, finance, education or healthcare. Pick the view, theme it, ship it.

Swipeable month & week

Expandable week ↔ month, controlled from code. Quick year and month jumps from the header.

Single, multi & range

Range presets, maximum length, blocked days, freeze, read-only and disabled states.

Planner & drag and drop

Multicolour event cards in five shapes. Drag notes or events onto any day.

Schedule view

Day to week time grid with drag to move, edge resize, work hours, blocked slots and a now line.

Type or pick

Masked input with validation and natural language like “next friday” or “in 3 days”.

Chrono toolbox

Business days, ages, ISO weeks, leap years, formatting, parsing, relative time and more.

Time zones

Daylight-saving aware zones with correct handling of skipped and repeated hours.

Rich events

Recurrence, exceptions, attendees, reminders, status, visibility and calendar file import/export.

Theme everything

Colours, shapes, sizes, text and motion. Light and dark follow your app automatically.

Developer first

Three lines to start. Every option when you need it.

Sensible defaults everywhere, builders that return null to keep the default, and a controller you can drive from anywhere in your app.

  • No setup, no delegates, no initialization
  • Month arithmetic that never overflows
  • Leap-year and daylight-saving safe
  • Right-to-left, large text and keyboard ready
  • Works on mobile, web and desktop
final controller = ChronoCalendarController();

ChronoCalendar(
  controller: controller,
  mode: ChronoSelectionMode.range,
  expandable: true,
  events: myEvents,
  availability: DateAvailability(disablePast: true),
  onRangeSelected: (range) => print(range),
);

controller.showWeekOf(DateTime(2026, 12, 21)); // collapse
controller.freeze();                          // lock

Chrono.addMonths(DateTime(2025, 1, 31), 1);   // Feb 28
Chrono.addBusinessDays(DateTime.now(), 10);
Chrono.parseNatural('next friday');
Chrono.timeAgo(date, locale: 'es');       // hace 3 días
