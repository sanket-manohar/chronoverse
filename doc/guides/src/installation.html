1About Chronoverse

Chronoverse is an all-in-one calendar and date toolkit for Flutter. A single package gives you month, week, year, schedule, agenda and planner views; single, multiple and range pickers; typed date input; recurrence; time zones; calendar conversions; and more than 80 ready-made date and time functions.

Zero dependencies

Chronoverse depends only on the Flutter SDK. It cannot cause version conflicts with other packages in your project.

No setup

No initialization call, no platform configuration, no permissions and no localization delegates are required.

Every platform

Android, iOS, web, macOS, Windows and Linux, from one code base.

Two entry points

chronoverse.dart for widgets and functions; core.dart for pure Dart functions without any UI.

3Preparing a macOS machine

Skip this section if Flutter already runs on your Mac (flutter doctor shows no errors for the platforms you build for).

  1. Download the Flutter SDK for macOS from the official Flutter website. Choose the build that matches your processor (ARM or x64).
  2. Extract it to a folder without spaces, for example ~/development/flutter.
  3. Add Flutter to your PATH. Open the Terminal app and run: 
    echo 'export PATH="$HOME/development/flutter/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
  4. Install the platform build tools for the targets you need: the official iOS/macOS developer tools from the Mac App Store for iOS and macOS apps, and the Android SDK for Android apps.
  5. Run the doctor and fix anything it reports: 
    flutter doctor
  6. Enable desktop and web targets if you want them: 
    flutter config --enable-macos-desktop
flutter config --enable-web
Chronoverse contains no native code, so it needs nothing extra on macOS: no pod files, entitlements or Info.plist keys.

4Preparing a Windows machine

Skip this section if Flutter already runs on your PC.

  1. Download the Flutter SDK for Windows from the official Flutter website.
  2. Extract it to a folder without spaces or special permissions, for example C:\src\flutter. Avoid C:\Program Files\.
  3. Add Flutter to your PATH. Open Start → Edit environment variables for your account, select Path, choose Edit → New and add C:\src\flutter\bin. Close and reopen any terminal.
  4. Turn on Developer Mode (Settings → Privacy & security → For developers). Flutter needs it to create symbolic links when building.
  5. Install the platform build tools for the targets you need: the C++ desktop build tools for Windows apps, and the Android SDK for Android apps.
  6. Run the doctor from a Command Prompt or terminal and fix anything it reports: 
    flutter doctor
  7. Enable desktop and web targets if you want them: 
    flutter config --enable-windows-desktop
flutter config --enable-web
Chronoverse uses only Dart and Flutter code, so Windows needs no extra libraries, DLLs or registry settings. File endings are normalised in the package, so it behaves the same whether your editor uses Windows or Unix line endings.

5Adding Chronoverse to your app

Option A: command line (recommended)

From the root folder of your Flutter project (the folder containing pubspec.yaml), run:

flutter pub add chronoverse

This adds the latest version to pubspec.yaml and downloads it. The same command works in the macOS Terminal, the Windows Command Prompt and any editor's built-in terminal.

Option B: edit pubspec.yaml

dependencies:
  flutter:
    sdk: flutter
  chronoverse: ^{{VERSION}}

Save the file, then run:

flutter pub get

Import it

// Widgets and every function:
import 'package:chronoverse/chronoverse.dart';

// Pure Dart functions only (servers, command-line tools, isolates):
import 'package:chronoverse/core.dart';
You do not need to add anything to MaterialApp. Languages, themes and time zones work out of the box.

6Verifying the installation

Replace the contents of lib/main.dart with this small app:

import 'package:chronoverse/chronoverse.dart';
import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: Scaffold(
        appBar: AppBar(title: Text('Leap year? ${Chrono.isLeapYear(2028)}')),
        body: ChronoCalendar(
          onDaySelected: (day) => debugPrint(Chrono.format(day, 'EEEE, d MMMM yyyy')),
        ),
      ),
    );
  }
}

Run it on any device:

flutter run            # pick a device when asked
flutter run -d macos   # on a Mac
flutter run -d windows # on a Windows PC
flutter run -d chrome  # in the browser

You should see a month calendar under the title Leap year? true. Tap a day and its full date is printed in the console. Swipe left or right to change month, and tap the month title to jump to another year.

7Running the example gallery

The package source includes a gallery app that demonstrates every widget. Download the source from the project repository, then:

cd chronoverse/example
flutter pub get
flutter run

On a wide window the gallery shows a side menu; on a phone it shows a bottom bar. Use the moon icon to switch to dark mode.

Keyboard, mouse and touch

On desktop and web, the arrow keys move between days, Page Up and Page Down change the page, and you can drag pages with the mouse or swipe with a trackpad. On touch devices all gestures work as expected.

10Troubleshooting

ProblemSolution
flutter is not recognisedFlutter's bin folder is not on your PATH. Repeat step 3 (macOS) or step 3 (Windows), then open a new terminal.
"The current Dart SDK version is …" / version solving failedYour SDK is older than required. Run flutter upgrade.
"Target of URI doesn't exist: package:chronoverse/…"Run flutter pub get and restart your editor's analysis server.
Windows build fails with a symlink errorTurn on Developer Mode (section 4, step 4).
Calendar shows English though the app is in another languagePass locale: ChronoLocale.of('fr'), or set the app's locale; Chronoverse follows it automatically.
Calendar overflows inside a ColumnThe month view has a natural height. Put it inside a scroll view, or use sixWeekMonths: true for a fixed height.
Times look shifted by one hourCheck daylight saving and the time zone of the data. Use ChronoTimeZone to convert explicitly.
Hot reload does not pick up a theme changeDo a hot restart; theme extensions are read when the app starts.

If a problem remains, open an issue on the project repository with your Flutter version (flutter --version), platform and a small code sample.
